CacheTTL ¶

Standard TTL values for different data types.

All values can be overridden via environment variables by prefixing with CACHE_TTL_ For example: CACHE_TTL_CALENDAR_EVENTS=300 will set CALENDAR_EVENTS to 300 seconds

Environment Variables

CACHE_TTL_CALENDAR_EVENTS: Calendar events cache (default: 900 seconds) CACHE_TTL_CALENDAR_INFO: Calendar info cache (default: 1800 seconds) CACHE_TTL_CALENDAR_FEED: Calendar feed cache (default: 600 seconds)

CALENDAR_EVENTS class-attribute instance-attribute ¶

CALENDAR_EVENTS = _get_cache_ttl('CALENDAR_EVENTS', 900)

CALENDAR_INFO class-attribute instance-attribute ¶

CALENDAR_FEED class-attribute instance-attribute ¶

CALENDAR_FEED = _get_cache_ttl('CALENDAR_FEED', 600)
